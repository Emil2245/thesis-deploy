## Limitaciones
- **Let's Encrypt no se ejercitó**: la VM está tras NAT. Se verificó con el emisor `selfsigned-ca` (certificado verificado con `curl --cacert`). La emisión ACME real queda pendiente de un servidor público.
- El modo con segundo servidor (`--agent`) no se ejercitó (una sola VM).
- El almacén S3 interno (SeaweedFS) está en el mismo servidor que la base; ver el manual (capítulo de respaldos).
- Las VM `k3s-lab-1/2/3` siguieron en ejecución y `aws-lab-1` apagada (sin tocar) durante todo el trabajo.
